##  Executive Overview

**PulseGrid (ArchPulse)** is an institutional-grade, single-page Web3 decentralized ecosystem and infrastructure dashboard built for **Circle Arc L1** — the high-throughput, sub-second finality Layer-1 blockchain powered by native USDC gas settlement.

Combining modern neo-brutalist and holographic glassmorphism aesthetics, PulseGrid delivers real-time consensus telemetry, sub-second DEX swaps, authentic cryptographic wallet verification, gamified community builder quests, institutional escrow settlements, and AI-driven market intelligence.

##  Key Architectural Features

### 1. Live Telemetry & Consensus Matrix (Protocol)
* **Real RPC Block Polling**: Direct JSON-RPC telemetry stream fetching block height, transaction counts, gas benchmarks, and throughput.
* **Consensus Health Radar**: Visualizes sub-second finality metrics, network latency, and consortium block production cadence.
* **Historical Gas Indexing**: Real-time monitoring of predictable institutional micro-gas (~0.001 USDC per transaction).

### 2. Institutional Validator Consortium
* **Authentic Node Operator Brand Registry**: Complete inspection profiles for Tier-1 institutional validators including **Circle**, **BlackRock**, **Visa**, **BNY Mellon**, **DTCC**, **Anchorage Digital**, **Coinbase Cloud**, **Fidelity Digital**, **Paxos**, and **Fireblocks**.
* **Consensus Deep Inspection**: Detailed node hardware profiles (EPYC 64 vCPU, 256GB ECC RAM, 10 Gbps fiber), voting power distribution, latency trackers, and validator address verification.

### 3. Pro Web3 Wallet & Asset Studio
* **Obsidian Holographic Hero Card**: Large-scale net worth display, dynamic 24h PnL ticker, USDC gas reserve indicators, and 1-click address clipboard copying.
* **Multi-Tab Asset Management**:
  * **Tokens & Balances**: Native USDC, Circle EURC, eBTC (Wrapped Bitcoin with testnet minting), and ARC Governance tokens.
  * **NFTs & Passes**: Holographic Arc Genesis Builder Pass (`#0042`) and Institutional Consortium Delegate Pass (`#0108`).
  * **On-Chain Activity**: Real-time transaction history logs featuring status pills (`Finalized ⚡`), method tags, and direct ArcScan hash links.
  * **Security & Keys**: EIP-191 / EIP-4361 signature authenticator and Arc RPC Network Switcher.

### 4. Precision DEX AMM Swap Engine
* **Circle SDK Synchronized Rates**: Algorithmic stablecoin liquidity routing (`1 USDC = 0.882639 EURC` | `1 EURC = 1.132966 USDC`).
* **Zero Price Impact**: High-depth constant product AMM liquidity curve for friction-free stablecoin conversions.
* **Full EVM Execution**: Interactive token flip, max balance auto-fill, custom slippage tolerance (0.1% – 1.0%), and instant builder XP rewards upon swap completion.

### 5. Gamified Daily Quests & On-Chain XP
* **Cryptographic Proof of Check-In**: Streak verification guarded by standard **EIP-4361 SIWE** `personal_sign` signature requests.
* **Real-Time Leaderboard**: Dynamically tracks wallet connections and builder achievements without fake mock data.
* **Live Community Feed**: Chronological transaction and quest achievement stream with direct block explorer validation.

### 6. AI Market Forecast & Gemini Copilot

### 7. Circle Escrow & Settlement Vault

##  Quick Start & Local Setup

### Prerequisites
* A modern web browser (Chrome, Brave, Firefox, or Edge)
* A Web3 Wallet extension (MetaMask, Rabby, or Coinbase Wallet)
* Node.js (Optional, for local static serving)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/promanas0/archpulse.git
   cd archpulse
   ```

2. **Run locally using any static HTTP server**:
   ```bash
   # Using npx serve:
   npx -y serve .

   # Or using Python 3:
   python -m http.server 3000
   ```

3. **Open in your browser**:
   Navigate to `http://localhost:3000/PulseGrid.html` or `http://localhost:3000`.

4. **Connect to Arc L1 Testnet**:
   * Click **"Switch RPC"** or **"Connect Wallet"** in the sidebar.
   * Confirm the network switch to Arc Testnet (`Chain ID: 5042002`).
