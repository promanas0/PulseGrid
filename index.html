Protocol Architecture

Built on Circle Arc L1

Arc L1 is a purpose-built Layer-1 blockchain combining programmable stablecoin rails, sub-second finality, and consortium-grade validator infrastructure.

Core Protocol Features

Sub-Second Block Finality
Arc L1 achieves ~0.4s block confirmation times using a delegated BFT consensus mechanism.
Native USDC Gas Currency
Unlike ETH-based networks, Arc L1 uses USDC as native gas. Predictable transaction costs (~0.001 USDC).
Consortium Validator Security
12 globally distributed validator nodes operated by regulated financial institutions ensure robust security.
Full EVM Compatibility
Full Ethereum Virtual Machine compatibility allows developers to deploy standard Solidity contracts seamlessly.
